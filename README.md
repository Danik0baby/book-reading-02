# Читальный зал

Веб-приложение для просмотра PDF-книги в виде интерактивного флипбука.

## Запуск

Нужен Node.js. В корневой папке проекта выполните:

```bash
npm install
npm start
```

Откройте в браузере [http://localhost:8000](http://localhost:8000).

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

> Не открывайте `index.html` напрямую через `file://`: приложению нужен HTTP-сервер для загрузки модулей и данных книги.

## Cloudflare Pages и загрузка книги

Сайт публикуется как обычные статические файлы из корня проекта. `node_modules` на сайте не требуется: минифицированная библиотека PDF.js и её worker находятся в `vendor/pdfjs/6.4.299/` и включены в Git. Для уже подготовленных файлов отдельная сборка на Pages не нужна.

Приложение получает `book-data/manifest.json`, затем запрашивает блоки по 64 КиБ из `book-data/chunks/` по требованию PDF.js. Это работает без HTTP Range и серверных функций. Исходный `book/backend.pdf` остаётся неизменным: блоки — точные копии его байтов. Для открытия нужны также служебные данные PDF и общие шрифты; один блок не обязательно соответствует одной странице.

Холсты создаются для текущего разворота и страниц, участвующих в перелистывании. Одновременно выполняются не более двух отрисовок, размер одного холста ограничен двумя миллионами пикселей. После перехода скрытые холсты, ссылки и ресурсы страниц освобождаются. Ссылки обрабатываются после появления изображения страницы.

Версия PDF.js и блоки с хешем в адресе кешируются надолго через `_headers`. Манифест проверяется при новом открытии. Файл `404.html` предотвращает подмену отсутствующих JS-файлов главной HTML-страницей.

## Файлы проекта

- `index.html` — страница приложения.
- `js/app.js` — загрузка и отображение PDF, управление страницами и масштабом.
- `js/bootstrap.js` — запуск и отображение ошибок загрузки модулей.
- `js/pdf-source.js` — получение нужных блоков PDF.
- `js/page-renderer.js` — очередь отрисовки и освобождение памяти.
- `js/pdf-links.js` — ссылки на страницах.
- `vendor/`, `book-data/` — подготовленные файлы для публикации.
- `book/backend.pdf` — PDF-книга, отображаемая при запуске.
- `assets/sounds/turning-a-page.ogg` — звук перелистывания.

После замены книги выполните `npm run prepare:assets` и `npm run check`, затем включите обновлённые `book-data/` и `vendor/` в коммит. Скрипт читает PDF, не переписывает и не сжимает его. Эту же команду можно использовать как команду сборки Pages, если нужна автоматическая подготовка. При обновлении версии PDF.js обновите её закреплённую версию в `package.json`, пути в JS/HTML и скриптах, затем снова подготовьте файлы.

## Управление

- Кнопки внизу страницы — переход к первой, предыдущей, следующей и последней странице.
- Угол страницы можно потянуть мышью или пальцем, чтобы перевернуть её.
- Кнопки лупы меняют масштаб, кнопка ноты включает или выключает звук, кнопка с углами включает полноэкранный режим.
- Клавиши `←` и `→` перелистывают страницы.
